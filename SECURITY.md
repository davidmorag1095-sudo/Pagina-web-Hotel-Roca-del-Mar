# Seguridad

- No guardar contraseñas, tokens, claves de API ni credenciales en el repositorio.
- Utilizar archivos `.env` locales para valores sensibles y mantener solo ejemplos sin secretos.
- Revisar dependencias y configuración antes de cada despliegue.
- Mantener protegidas las cuentas de GitHub, hosting y dominio mediante autenticación de dos factores.
